# Availability & Time conflict detection 

This is an algorithm, specification or problem-solving template (call it however you like) that 

provides a more standardized way of thinking about time, of talking about time and working with time, 

when dealing with problems of availability, conflict and time overlaps.

The goal is to reduce cognitive effort, facilitate problem-solving and make our algorithms more reliable and easier to reason about.
